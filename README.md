# Fambridge Website

Complete bilingual static website for **Fambridge Trading Inc.**

## Visual direction

- Warm ivory / paper surfaces rather than large orange fields
- Ink navy as the primary brand colour
- Orange retained only as a restrained accent
- Editorial serif headings for a quieter, more cultural tone
- The header mark is derived directly from the light bridge/people element in the original Fambridge logo; its geometry is not redrawn
- English and French versions share one design system

## Local preview

From this directory:

```bash
python3 -m http.server 8000
```

Open:

- http://localhost:8000/
- http://localhost:8000/fr/

## Deployment

This package is ready for a static host such as GitHub Pages. `CNAME`, `robots.txt`, and `sitemap.xml` are included.
