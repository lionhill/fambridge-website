# Fambridge Website

Official website source for Fambridge Inc.

## Publishing

This repository is intended to be published with GitHub Pages from the `main` branch root.

Custom domain: `fambridge.ca`

## Structure

- `index.html` — public landing page
- `assets/css/site.css` — site styles
- `CNAME` — GitHub Pages custom-domain configuration

## DNS

Do not change DNS until GitHub Pages has been enabled and the temporary GitHub Pages URL is confirmed working.
