# Fambridge Website — V4 visual refinement

This version removes hard background splits and full-width colour slabs.

Key changes:
- One continuous warm ivory / paper canvas.
- Home hero uses a soft, edge-free cool mist glow on the right instead of a percentage-based background split.
- "Bringing People Closer." has no background panel; hierarchy comes from typography and a fine vertical rule.
- Section contrast is created with feathered gradients, whitespace and hairlines instead of block-like full-width fills.
- Product and business sections stay on the same continuous canvas.
- Text, information architecture and bilingual content are unchanged from the refined site.

The hero ambient wash is decorative and does not define layout, so browser zoom does not create a moving hard boundary.
